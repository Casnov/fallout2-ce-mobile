# Этап 5: безопасный ZIP-импорт на телефоне

Сборка `5009c4e6`. Можно выполнить промежуточный прогон на нынешней Chrome PWA
Redmi 15C. iPhone остаётся целевой платформой; его прогон новой схемы хранения,
сейвов и импорта объединим перед бетой. Звук/Яндекс Клавиатуру здесь не проверяем.

Открыть **существующую** Chrome PWA/техническую страницу по прежнему адресу:
https://ADDRESS-FROM-https-test.py/device-check.html

Не удалять приложение, данные сайта или файлы игры. ZIP нужен для проверки
замены, а не для обновления самого приложения. Закрыть другие игровые окна.
Интернет оставить включённым; Mac должен бодрствовать: это временная раздача,
холодный офлайн-запуск приложения будет на этапе 8. При смене адреса/браузера
получится другое хранилище. Нынешние сохранения находятся в Chrome PWA.

1. Полностью закрыть старое приложение и открыть заново. На технической странице
   проверить номер `5009c4e6`, нажать «Проверить локальное чтение» и скопировать
   исходный отчёт. Если номер другой, обновить страницу, не очищая данные сайта.
   Установка должна найтись без нового ZIP; слоты/настройки должны остаться.
2. Раскрыть «Что именно проверяется», скачать маленький `invalid-crc.zip`
   (277 байт) и выбрать его через «Выбрать ZIP для замены игры» из «Загрузок».
   Сначала появится список из двух искусственных файлов. Это **намеренно
   повреждённый тест**, не игра. Нажать «Заменить игру»: должна появиться ошибка
   повреждённого ZIP. Прежняя установка остаётся доступной.
   Проверить локальное чтение, запустить игру и **загрузить существующий сейв**.
   Затем выйти через главное меню → «Выход» и открыть техническую страницу.
3. Выбрать свой прежний рабочий ZIP полной игры с RPU. Проверить список файлов.
   Нажать «Отказаться от этого ZIP»: установленная игра не меняется.
   Затем выбрать тот же ZIP повторно, подтвердить замену и во время сообщения
   «Подготовлено…» нажать «Отменить», дождавшись результата.
   Если уже идёт «Завершаю проверку…», отмена закончилась: нужно дождаться
   завершения, не считать это ошибкой. Для проверки отмены повторить с более
   ранним нажатием. После отмены прочитать/запустить прежнюю игру без нового ZIP.
4. Проверить прерывание: ещё раз начать замену тем же рабочим ZIP и, пока идёт
   «Подготовлено…», полностью закрыть приложение через список приложений.
   Открыть прежний значок и дождаться уборки временных данных. Прежняя игра
   должна найтись; повторить локальное чтение и загрузку существующего сейва.
   Если телефон успел завершить установку до закрытия, это успешная установка,
   а не доказанное прерывание; описать, что успело произойти.
5. Ещё раз выбрать **тот же рабочий ZIP**, подтвердить и дождаться успешного
   завершения. Проверить локальное чтение. Запустить игру, загрузить прежний
   ручной или быстрый сейв и проверить сохранность заметной настройки.
   Новое поколение ресурсов получает другой `installed.run`, пользовательские
   слоты и настройки остаются. Архивная SAVEGAME не заменяет текущие сейвы.
   Не заменять игру другой версией RPU в этом тесте: совместимость модов — этап 6.
6. Полностью закрыть/открыть PWA, проверить чтение и скопировать итоговый отчёт.
   Прислать исходный и итоговый JSON и коротко отметить результаты пунктов 2–5.
   Не нужно пересылать сам ZIP игры или содержимое сохранений.

Ожидаем `test=fallout2-stage5`, resource DB v2/format 1, user format 2,
`read.verified=true`. После успешного импорта появляется `installed.stage5`:
транзакции, хеширование, запись, новые/переиспользованные байты и замеры хода
распаковки. Сравнивать скорость первого импорта и повторного импорта без учёта
переиспользования данных нельзя. Номер исходной установки должен сохраниться
после отказа, отмены и подтверждённого прерывания; после успешной замены — смениться.

Не нужно специально заполнять память телефона. Реальная ошибка транзакции
квоты, неверные пути/размеры/CRC, закрытая сессия и сохранность прежнего поколения
проверены на искусственных данных. Аппаратный прогон дополняет эти проверки,
но не имитирует все аварии хранения. Резервирование/экспорт сейвов — этап 6.

## Результат проверки 25 октября 2026

Пользователь выполнил пункты2–5 на нынешней Chrome PWA Redmi15C и подтвердил
отказ неверного ZIP, отмену/полное закрытие во время подготовки и успешную
замену с прежними сейвами/настройками. Сборка5009c4e6: run сменился с e1aff4ba…
на eeb3986c…,2240файлов и1,628,730,813байт ресурсов;5слотов/19настроек/records
сохранились. Локальное чтение до/после verified=true. Прогон принят на Android;
повтор без новых изменений не нужен. iPhone остаётся объединённым прогоном.

Замена заняла16min30s;1,571транзакция; все блоки переиспользованы (newBytes=0).
Основное время в хвосте и обработке мелких файлов:19.27MB/1541файл за644s,
при суммарном writeMs28.9s и hashMs7.2s. Точная причина задержки не выделена;
это не доказанная проблема записи в IndexedDB или измеренное ускорение.
