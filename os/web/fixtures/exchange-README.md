# Synthetic save exchange fixtures

These ZIPs contain a fabricated 2000-byte SAVE.DAT header with the description
`roundtrip`, a short synthetic automap payload and port records. They contain no
original Fallout game assets and are never packaged into the application.
They validate transport/catalog metadata, not a playable game save.

- `web-exchange.zip`: generated by the format-3 production exporter in the
  WebKit in-app browser, from an OPFS file and downloaded through the real UI.
  It follows an atomic import of android-exchange.zip. ZIP Store entries have
  known CRCs/no data descriptors; Android GameSavesTest consumes the result.
- `android-exchange.zip`: produced by real Android GameSaves.export after importing
  that web fixture in GameSavesTest.webExportIsImportedAndExportedByAndroid.
  Node tests import it; the WASM user-saves fixture then opens the committed slot
  using actual SaveCatalog/SaveRecords and checks native identity/composition.

The Android test also emits a fresh comparison artifact under
out/web/iphone-test/stage6-android-exchange.zip. Tests do not regenerate the
checked-in fixtures. All contents are synthetic and can be inspected with any
ordinary ZIP tool.
