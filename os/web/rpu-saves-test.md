# Этап 6: актуальная проверка

Обновление: **1d756577 уже выдана по прежнему адресу**. Проверка большого ZIP
в Safari на iPhone принята: скачанный файл выбран из «Файлов», размер и крайние
записи совпали. Web Share удалён; экспорт использует «Сохранить ZIP» для любого
размера. Теперь выполняются пункты 1–4 ниже в установленной PWA. Игровой ZIP
повторно не нужен, данные сайта и приложение не удалять.

Предыдущая последовательность подготовки сохранена ниже как история.

Реализация большого обмена сейвами подготовлена отдельной сборкой. Нынешний
адрес телефона пока сохраняет прежнюю игру; добавлена только изолированная
страница проверки большого ZIP. Сейвы на телефоне ещё не мигрировались.

**Сначала:** [короткий тест ZIP на iPhone](large-saves-test.md). Сейчас iPhone
недоступен, поэтому аппаратная приёмка ожидает его. Переустановка и игровой
ZIP для этого теста не нужны.

**После этого**, когда новая сборка будет выдана по прежнему адресу:

1. Открыть игру в прежнем браузере/ярлыке. Дождаться переноса сейвов, загрузить
   один знакомый слот и сверить героя/локацию. Игровой ZIP не требуется.
2. Создать обычный слот «Тест6». Через **Настройки → Файлы игры → Экспорт
   сохранений** сохранить один ZIP всех слотов. Выбора отдельных слотов нет.
3. Если ZIP получен, удалить в игре только «Тест6», остальные оставить.
   Через импорт открыть экспортированный ZIP: предпросмотр должен предложить
   **«Добавить»**, пропуская существующие сейвы. Подтвердить добавление.
4. Полностью закрыть и открыть приложение/вкладку. Загрузить «Тест6» и один
   прежний сейв. Проверить сохранённую настройку и быстрый сейв.

Достаточно написать: «миграция / ZIP / восстановление / перезапуск — ок».
Если шаг не прошёл — сообщить его и текст ошибки. Полную замену всех настоящих
сейвов сейчас не делать. Холодный офлайн-запуск — следующий отдельный этап8.

Автотесты берут на себя 1000 слотов, ZIP64, 70 000 файлов, CRC, отмену, квоту,
обрывы, миграцию, предыдущий checkpoint, native каталог WASM и обмен Android.
Они не подменяют загрузку реальных RPU-сейвов на телефоне. Полная матрица перед
публичной бетой: docs-private/web-stage6-full-device-check.md.
